# 04. DML and Joins

Четвёртый проект: продолжение темы соединений и переход к изменению данных. Первая половина — аналитические выборки с группировками и разностями множеств, вторая — `INSERT` (в том числе с вычислением ключей через подзапросы), `UPDATE` и `DELETE`, которые пошагово добавляют и откатывают тестовые данные.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day03_ex00.sql` | что из меню 800–1000 ела Кейт: четыре `JOIN` и сортировка по разным направлениям |
| `day03_ex01.sql` | позиции меню, которые ни разу не заказывали (`NOT IN` с `DISTINCT`) |
| `day03_ex02.sql` | те же позиции с именем, ценой и пиццерией |
| `day03_ex03.sql` | пиццерии, где число визитов мужчин и женщин не совпадает: `CASE` внутри `SUM` + `HAVING` |
| `day03_ex04.sql` | пиццерии, куда не ходили женщины или не ходили мужчины: `UNION` двух агрегатов |
| `day03_ex05.sql` | куда Андрей приходил, но ничего не заказывал: `EXCEPT` между визитами и заказами |
| `day03_ex06.sql` | self-join меню: одна пицца по одинаковой цене в разных пиццериях |
| `day03_ex07.sql` | `INSERT` новой позиции в меню |
| `day03_ex08.sql` | `INSERT` с вычислением нового `id` через подзапрос `max(id)+1` и поиском пиццерии по имени |
| `day03_ex09.sql` | два `INSERT` в визиты: Денис и Ирина приходят в Dominos |
| `day03_ex10.sql` | два `INSERT` в заказы для тех же людей |
| `day03_ex11.sql` | `UPDATE`: скидка 10% на греческую пиццу |
| `day03_ex12.sql` | `INSERT … SELECT`: заказ греческой пиццы всеми людьми сразу |
| `day03_ex13.sql` | `DELETE`: откат вставленных заказов и позиций меню |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day03_ex00.sql
```

Упражнения `ex07`–`ex13` меняют данные и рассчитаны на выполнение по порядку.
