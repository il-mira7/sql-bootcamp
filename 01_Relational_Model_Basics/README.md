# 01. Relational Model Basics

Первый проект буткемпа: знакомство с реляционной моделью на примере базы «пиццерии» (люди, пиццерии, меню, визиты, заказы). Отрабатываются базовые выборки, фильтрация и сортировка, логические условия, форматирование строк, скалярные подзапросы, CTE и условная логика `CASE`.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day00_ex00.sql` | выборка имени и возраста людей, живущих в Казани |
| `day00_ex01.sql` | то же с фильтром по полу и сортировкой по имени |
| `day00_ex02.sql` | пиццерии с рейтингом в диапазоне 3.5–5 — двумя эквивалентными способами: `BETWEEN` и через `>=`/`<=` |
| `day00_ex03.sql` | визиты с заданным `id` или попавшие в интервал дат, сортировка по убыванию |
| `day00_ex04.sql` | сборка персональной строки «имя (age:…, gender:…, address:…)» через `FORMAT` |
| `day00_ex05.sql` | имена людей, заказавших конкретные позиции меню в заданную дату — скалярный подзапрос в `SELECT` |
| `day00_ex06.sql` | тот же запрос через CTE плюс пометка `true/false` для конкретного имени через `CASE` |
| `day00_ex07.sql` | распределение людей по возрастным интервалам через каскад `CASE` |
| `day00_ex08.sql` | выборка заказов с чётными `id` (остаток от деления) |
| `day00_ex09.sql` | подзапросы в `SELECT` и в `FROM`: отчёт «кто и где был» по визитам за период |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day00_ex00.sql
```
