# 05. Views and Snapshots

Пятый проект: представления и материализованные представления. Создаются обычные `VIEW` как переиспользуемые «виртуальные таблицы», `MATERIALIZED VIEW` как снимок результата, обновление снимка через `REFRESH` и удаление объектов через `DROP`.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day04_ex00.sql` | два представления: женщины и мужчины из таблицы людей |
| `day04_ex01.sql` | объединение списков имён поверх созданных представлений |
| `day04_ex02.sql` | представление-календарь января 2022 на основе `generate_series` |
| `day04_ex03.sql` | дни месяца без визитов: `EXCEPT` между календарём и фактами |
| `day04_ex04.sql` | симметрическая разность посетителей двух дат, оформленная как `VIEW` |
| `day04_ex05.sql` | представление с ценами и скидкой 10% (вычисляемый столбец) |
| `day04_ex06.sql` | `MATERIALIZED VIEW`: снимок «где ел Дмитрий 8 января и платил меньше 800» |
| `day04_ex07.sql` | добавление нового визита и обновление снимка через `REFRESH MATERIALIZED VIEW` |
| `day04_ex08.sql` | удаление всех созданных представлений (`DROP VIEW` / `DROP MATERIALIZED VIEW`) |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day04_ex00.sql
```

Упражнения создают объекты в базе и выполняются по порядку.
