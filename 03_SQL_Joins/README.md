# 03. SQL Joins

Третий проект — глубокое погружение в соединения. Отрабатываются `LEFT`/`RIGHT`/`FULL OUTER JOIN`, поиск «недостающих» строк через `JOIN` с `generate_series`, обработка пустых значений в полном соединении и self-join таблицы на саму себя.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day02_ex00.sql` | anti-join: пиццерии, в которых не было ни одного визита (`LEFT JOIN … IS NULL`) |
| `day02_ex01.sql` | дни января без визитов двух людей: `RIGHT JOIN` календаря из `generate_series` с визитами |
| `day02_ex02.sql` | `FULL OUTER JOIN` визитов с людьми и пиццериями, пропуски заменяются на `-` через `CASE` |
| `day02_ex03.sql` | как `ex01`, но календарь оформлен через CTE |
| `day02_ex04.sql` | цены перрони и грибной пиццы по пиццериям: подзапрос в `FROM` + `JOIN` |
| `day02_ex05.sql` | фильтрация людей по возрасту и полу |
| `day02_ex06.sql` | что заказывали Анна и Денис: три `JOIN` в цепочке |
| `day02_ex07.sql` | где Дмитрий ел 8 января и при этом пицца стоила дешевле 800 |
| `day02_ex08.sql` | мужчины из Москвы и Самары, заказавшие конкретные пиццы, сортировка по убыванию |
| `day02_ex09.sql` | женщины, заказавшие и перрони, и сырную: пересечение двух выборок через `INTERSECT` |
| `day02_ex10.sql` | self-join: пары людей, живущих по одному адресу |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day02_ex00.sql
```
