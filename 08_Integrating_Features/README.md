# 08. Integrating Features

Восьмой проект: развитие схемы данных под новую фичу — персональные скидки в пиццериях. Создаётся своя таблица с первичными и внешними ключами, данные для скидок вычисляются агрегацией истории заказов, затем добавляются ограничения `CHECK`/`DEFAULT`, комментарии к объектам и последовательность для автогенерации ключей.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day06_ex00.sql` | таблица `person_discounts` с `PRIMARY KEY` и `FOREIGN KEY` на людей и пиццерии |
| `day06_ex01.sql` | наполнение скидок из истории заказов: размер скидки зависит от числа заказов (`CASE` + `COUNT`), ключи через `ROW_NUMBER() OVER ()` |
| `day06_ex02.sql` | расчёт цены с учётом скидки: `TRUNC` и `CASE` для нужного числа знаков |
| `day06_ex03.sql` | уникальный индекс «человек + пиццерия» и проверка плана через `EXPLAIN ANALYZE` |
| `day06_ex04.sql` | `ALTER TABLE`: `CHECK` на `NOT NULL` и диапазон скидки 0–100, `DEFAULT 0` |
| `day06_ex05.sql` | документирование схемы: `COMMENT ON TABLE` / `COMMENT ON COLUMN` |
| `day06_ex06.sql` | `SEQUENCE` как значение по умолчанию для `id` и синхронизация через `setval` |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day06_ex00.sql
```

Упражнения меняют схему и данные, выполняются по порядку.
