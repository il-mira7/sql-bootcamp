# 07. Database Indexes

Седьмой проект: индексы и доказательство их пользы через план выполнения. Создаются простые индексы на внешних ключах, функциональный индекс по `UPPER(name)`, составной, уникальный и частичный индексы; каждый раз эффект проверяется `EXPLAIN ANALYZE` с отключённым последовательным сканированием.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day05_ex00.sql` | простые B-tree индексы на внешних ключах меню, визитов и заказов |
| `day05_ex01.sql` | `EXPLAIN ANALYZE` для `JOIN` меню и пиццерий; `SET enable_seqscan = off` для принудительного использования индексов |
| `day05_ex02.sql` | функциональный индекс по `UPPER(name)` и поиск без учёта регистра |
| `day05_ex03.sql` | составной индекс `(person_id, menu_id, order_date)` под конкретный запрос |
| `day05_ex04.sql` | уникальный индекс `(pizzeria_id, pizza_name)` и поиск по префиксу `LIKE 'c%'` |
| `day05_ex05.sql` | частичный уникальный индекс только для строк с определённой датой заказа |
| `day05_ex06.sql` | индекс по рейтингу под запрос с оконной функцией |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day05_ex00.sql
```

Упражнения создают индексы и рассчитаны на выполнение по порядку.
