# 09. OLAP Aggregations

Девятый проект — агрегация как основа аналитики. Считаются рейтинги и топы посетителей и пиццерий, объединяются агрегаты разных типов через `UNION`, добавляются `HAVING`-фильтры, сводные статистики (`AVG`/`MAX`/`MIN`) и оконная функция поверх агрегированных данных.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day07_ex00.sql` | число визитов по каждому человеку |
| `day07_ex01.sql` | топ-4 людей по числу визитов |
| `day07_ex02.sql` | топ-3 пиццерий по визитам и по заказам: `UNION` двух агрегатов с меткой типа действия |
| `day07_ex03.sql` | суммарная активность пиццерий: CTE + `UNION` + повторная агрегация |
| `day07_ex04.sql` | люди с более чем тремя визитами (`HAVING`) |
| `day07_ex05.sql` | уникальные имена людей, делавших заказы (`DISTINCT`) |
| `day07_ex06.sql` | по пиццериям: число заказов, средняя/максимальная/минимальная цена |
| `day07_ex07.sql` | глобальный средний рейтинг всех пиццерий |
| `day07_ex08.sql` | заказы в разрезе «адрес человека — пиццерия» |
| `day07_ex09.sql` | сравнение двух мер по возрасту жителей адресов: формула `(max − min/max)` против среднего |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day07_ex00.sql
```
