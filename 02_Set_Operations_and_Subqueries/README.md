# 02. Set Operations and Subqueries

Второй проект: множественные операции над выборками и разные способы соединения данных. Сравниваются `UNION` и `UNION ALL` (дедупликация против сохранения дублей), пересечения и разности множеств через `INTERSECT`/`EXCEPT`, а также `CROSS`/`NATURAL JOIN` и альтернативы `NOT IN` и `NOT EXISTS` для anti-join.

## Упражнения

| Файл | Что делает |
|------|------------|
| `day01_ex00.sql` | объединение идентификаторов и имён из меню и людей через `UNION` (с дедупликацией) |
| `day01_ex01.sql` | то же через `UNION ALL` — все строки, включая дубли |
| `day01_ex02.sql` | демонстрация дедупликации: `UNION` и `UNION ALL` на одинаковых данных |
| `day01_ex03.sql` | пересечение дат визитов и заказов через `INTERSECT ALL` |
| `day01_ex04.sql` | разность множеств через `EXCEPT ALL`: кто заказывал, но не приходил в этот день |
| `day01_ex05.sql` | `CROSS JOIN` — все возможные пары «человек — пиццерия» |
| `day01_ex06.sql` | пересечение по именам через `INTERSECT ALL` с `INNER JOIN` с обеих сторон |
| `day01_ex07.sql` | отчёт о заказах с форматированием строки через `FORMAT` |
| `day01_ex08.sql` | тот же отчёт через `NATURAL JOIN` |
| `day01_ex09.sql` | пиццерии, куда никто не приходил: вариант через `NOT IN` и через `NOT EXISTS` |
| `day01_ex10.sql` | цепочка из четырёх `JOIN`: сводка «кто, что и где заказывал и посещал» |

## Запуск

```bash
psql -d pizza -f materials/model.sql
psql -d pizza -f src/ex00/day01_ex00.sql
```
