# 12. Data Warehouse Fundamentals

Командный проект (rush): основы Data Warehouse на задаче финтех-балансов. Из разрозненных таблиц пользователей, балансов и истории курсов валют собирается витрина: итоговые суммы в USD на дату отчёта, аккуратная обработка отсутствующих значений и сопоставление балансов с ближайшими по времени курсами.

Схема и тестовые данные — в `materials/rush01_model.sql`.

## Упражнения

| Файл | Что делает |
|------|------------|
| `team01_ex00.sql` | общий отчёт по балансам в USD: `FULL JOIN` пользователей, балансов и последних курсов (`MAX(updated) OVER (PARTITION BY …)`), подстановка `COALESCE` для отсутствующих имён и курсов |
| `team01_ex01.sql` | сопоставление каждого баланса с ближайшим курсом по времени: приоритет курса «до» или «после» обновления баланса через `ROW_NUMBER` и вспомогательную PL/pgSQL-функцию приоритета интервала |

## Запуск

```bash
createdb fintech
psql -d fintech -f materials/rush01_model.sql
psql -d fintech -f src/ex00/team01_ex00.sql
```
