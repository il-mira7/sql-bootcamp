# 06. Traveling Salesman Problem

Командный проект: задача коммивояжёра, решённая чисто на SQL. По таблице маршрутов между четырьмя городами строится полный обход с возвратом в исходную точку; перебор маршрутов реализован рекурсивным CTE, посещённые города хранятся в массиве, что не даёт циклу зациклиться.

## Упражнения

| Файл | Что делает |
|------|------------|
| `team00_ex00.sql` | таблица маршрутов с ценами + `WITH RECURSIVE`: перебор всех туров из «a» с возвратом, выбор маршрута минимальной стоимости |
| `team00_ex01.sql` | то же, но выводятся и самый дешёвый, и самый дорогой туры |

## Запуск

Файл `ex00` сам создаёт и наполняет таблицу `route`, отдельная схема не нужна:

```bash
psql -d pizza -f src/ex00/team00_ex00.sql
```
